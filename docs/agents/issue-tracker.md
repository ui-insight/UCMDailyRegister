# Issue tracker: GitHub

Issues and PRDs for this repository live as GitHub issues in `ui-insight/UCMDailyRegister`. Use the GitHub app when available and the `gh` CLI for operations it does not cover.

## Conventions

- **Create an issue:** create it in `ui-insight/UCMDailyRegister` with a concise title, a complete Markdown body, and the appropriate labels.
- **Read an issue:** fetch the full body, labels, and comments before acting on it.
- **List issues:** include issue number, title, body, labels, and comments, filtered to the relevant state or label.
- **Comment on an issue:** add a top-level issue comment without rewriting the issue body unless explicitly requested.
- **Apply or remove labels:** preserve unrelated labels and change only the intended workflow labels.
- **Close an issue:** include a short completion or disposition comment.

Infer the repository from `git remote -v` when operating inside this clone.

## When a skill says "publish to the issue tracker"

Create a GitHub issue in `ui-insight/UCMDailyRegister`.

## When a skill says "fetch the relevant ticket"

Read the GitHub issue's full body, labels, and comments.
